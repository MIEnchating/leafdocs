# Motion and surface refinement

Scope: `/root/workspace/new-api-docs/src/components/{public-shell,reveal,icons,code-block}.tsx`, public page/layout CSS, login and editor presentation. No auth, database, publishing or wheel-event changes.

1. Establish Soft Structuralism + Editorial Split: silver background, Geist sans typography, Phosphor light icons, floating detached navigation, two-column hero with interactive guide links. Below 768px use a single column with 16px horizontal padding and no overlap or rotation. Nest major surfaces inside softly tinted shells with concentric radii.
2. Add motion tokens to global CSS: `--ease-ui: cubic-bezier(.2,.8,.2,1)`, `--ease-spatial: cubic-bezier(.32,.72,0,1)`, `--duration-ui: 160ms`, `--duration-panel: 240ms`, `--duration-editorial: 800ms`. Existing reveal easing `cubic-bezier(.16,1,.3,1)` remains the editorial easing. Animate only transform and opacity; no animated blur or scroll listeners.
3. Replace public menu/theme/search wrappers with a reusable controlled native dialog. Use `showModal()` / `close()` for focus containment and Escape. Keep DOM mounted, use discrete display/overlay transitions with 12px translation for panels. Search is 120ms on pointer activation and immediate on Ctrl/Cmd+K. Native focus restoration must survive rapid reopen. Mobile link reveal is 240ms with 35ms bounded stagger; prevent background scrolling while a modal is open.
4. Keep reveal content visible in server HTML. Do not hide above-fold content after hydration; use IntersectionObserver to reveal offscreen content once with 20px translation, 800ms duration, and 60ms stagger capped at 180ms. Focusing an unrevealed child must expose it immediately. Reduced motion disables all displacement and delays. Remove editorial reveals from editor document switches.
5. Add nested circular trailing arrow containers to primary CTAs. Pointer hover translates the arrow by (2px,-2px), press scales to .98. Fine-pointer media queries prevent sticky touch hover. Admin state acknowledgement should be 160ms opacity only; editor text and keyboard navigation remain immediate.
6. Verification: production build; desktop/mobile visual review; native dialog Escape, Tab containment, return focus, rapid reopen, route changes and breakpoint changes; theme persistence and search; reduced motion and no-JS login; existing cross-browser code scrolling and login regression; extension-injected root attribute hydration check. Inspect animations at reduced playback speed and ensure scrolling containers receive no animated transforms or blur.
